# MML 2.0.0: the release build, the migration guide, the doc links

Owner decisions 2026-11-15: the family-standards release is 2.0.0, with a migration guide, as every major from v1 on.

## The Releases workflow

Red since ad50fd9 (last green 3b1d4b9, 2026-08-11). `nix build .#cross-x86_64-linux` reproduced it: cargoBuildHook ran with no `--features`, so no binary was built and the postInstall run of `$out/bin/mml` exited 127. flake.lock pins pimalaya/nix at cc4f9e1, whose mkDefault hands the package `defaultFeatures = true` and `features = ""`; default.nix split that into `[""]`, package.nix appended `cli`, and under `__structuredAttrs` the hook tests the array's first element, empty, so it passes no feature. default.nix now drops empty entries, as tcard and tcal already do; the cross build then ran with `--features=cli` and installed bin/mml.
